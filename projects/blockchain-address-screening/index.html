The problem

Compliance teams need risk and financial data for blockchain addresses. Provider coverage varies by chain, and reviewers need access to earlier screening results.

How the service works

Choosing providers by chain

The service checks the configured risk and financial providers against the requested chain’s coverage. If either configured provider lacks support for that chain, the service uses the chain-level default for that type of data. Provider adapters keep response mapping behind a shared interface.

Reviewing past checks

Complete checks are saved to PostgreSQL in the background. Reviewers can retrieve the latest result or browse paginated screening history. A report request starts background generation and returns a report ID for later download.
