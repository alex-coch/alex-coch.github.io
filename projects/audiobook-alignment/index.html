Matching audiobook narration to text

The problem

A book contains passages. Its audiobook contains a continuous timeline. Given a passage, the alignment task is to find where the narrator starts and finishes reading it.

My contribution

I built the Python pipeline that processes the written text and audio, orchestrated the work with Apache Airflow, and deployed a dedicated service for GPU inference.

How it works

  1. Inputs
    Book text and narration
  2. Processing
    Airflow pipeline and GPU inference
  3. Alignment
    Text mapped to audio time ranges

Airflow coordinates the processing steps. A dedicated GPU worker runs the model that matches the narration to the text.

Result

The GPU inference service runs in production as part of the audiobook alignment pipeline.
